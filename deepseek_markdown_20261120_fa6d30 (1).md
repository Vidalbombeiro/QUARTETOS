# 5º Encontro de Quartetos — Sorteio

Página web simples para inscrição em um sorteio do **5º Encontro de Quartetos**.
O participante informa nome, telefone/WhatsApp e se deseja um presente especial.
Os dados são enviados para uma planilha do Google Sheets via Google Apps Script.

---

## 📋 Funcionalidades

- Formulário com validação básica (nome e telefone obrigatórios)
- Envio assíncrono (sem recarregar a página) via `fetch`
- Feedback visual: botão "Enviando..." e mensagem de sucesso
- Layout responsivo, com as cores do cartaz do evento (azul escuro + dourado)
